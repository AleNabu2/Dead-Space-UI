# Dead Space UI Replica

Réplica de interfaz web inspirada en el universo de *Dead Space*, desarrollada como proyecto académico de diseño y desarrollo front-end.

Este proyecto se centra en la construcción de una interfaz visual inmersiva utilizando HTML y CSS, enfocada en estética sci-fi, composición UI y experiencia de usuario.

---

## Objetivo del proyecto

Recrear una interfaz temática inspirada en *Dead Space* con el fin de practicar:

- Diseño de interfaces oscuras y temáticas (UI sci-fi)
- Maquetación estructurada en HTML
- Estilización avanzada con CSS
- Organización visual y jerarquía de información
- Simulación de experiencia interactiva tipo videojuego

---

## Tecnologías utilizadas

- HTML5
- CSS
- Diseño UI inspirado en videojuegos sci-fi

---

## Características principales

- Estética oscura inspirada en *Dead Space*
- Interfaz modular tipo dashboard futurista
- Componentes visuales estilizados (cards, HUD, paneles)
- Enfoque en atmósfera inmersiva
